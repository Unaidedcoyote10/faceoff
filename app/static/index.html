Presets

Tick any that apply. They run together with the lines below. Emails, phone numbers, and money follow patterns (jane@example.com, (415) 555-2671, +44 20 7946 0958, $1,234.56). A string of digits with no separators is left alone, so an account number is not treated as a phone. Names, addresses, and locations are guesses: titles like “Dr. Jane Smith”, a “Name:” line, a short list of common given names, US-style streets and PO Boxes, and a fixed list of countries, states, and major cities. They miss unusual names, small towns, non-US addresses, lowercase text, and anything split across two lines, and they can cover a word that only looks like a name or a place (Georgia, Dr. Pepper). Not a certified redaction tool. Review every page.

Browser extension · Faceoff Syncextension-only

Instagram sync is extension-only. Faceoff Sync sends posts you save on Instagram (photos + videos) from your own logged-in Brave/Chrome tab into the Saved tab, unprocessed — pick which photos to blur or box there (videos stay raw). This server never contacts Instagram and never accepts a session cookie or sessionid.

Download extension (.zip)

Install: unzip → chrome://extensions (or brave://extensions) → Developer mode → Load unpacked → pick the faceoff-sync folder → pin it. Re-pair if Sync now stays disabled: generate a token here → extension Settings → paste your Faceoff URL and the token → Save → Allow host access if asked → open a visible instagram.com tab → Sync now.
